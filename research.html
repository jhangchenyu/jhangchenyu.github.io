01 / QUANTUM SCIENCE

2018 — 2022
實驗平台開發

離子阱量子計算實驗平台

Trapped-ion Quantum Computing Platform

參與單離子捕獲平台開發，將多能階原子系統的數值模型與光譜量測相互連結。工作涵蓋 EIT 光譜、Python 實驗自動化，以及支援平台運作的光學、真空與控制系統。

  • Trapped ions
  • EIT spectroscopy
  • Lindblad equation
  • Python
理論與模擬
以 Lindblad 方程模擬多能階原子系統的非線性光譜。
實驗與控制
EIT 光譜量測、實驗控制自動化與資料擷取。
多能階建模與 EIT 光譜

使用 Lindblad 方程描述原子系統，進行非線性光譜的數值模擬，並參與電磁誘發透明（Electromagnetically Induced Transparency, EIT）光譜量測。

建模與量測是此研究的兩個相互連結的部分：前者描述原子系統的動態，後者提供實驗中的光譜資訊。

實驗平台與自動化
  • 使用 Python 自動化實驗控制與資料擷取。
  • 建立離子源準備及光譜校準流程。
  • 參與真空腔體、光路與雷射頻率控制電路設計。

02 / RF ENGINEERING

射頻設計與模擬

螺旋共振器與射頻阻抗匹配

Helical Resonator & RF Impedance Matching

使用 HFSS 設計約 100 MHz 頻段的阻抗匹配元件，並設計方向耦合器監測訊號振幅。這項工作連結電磁模擬、射頻元件設計與實驗系統的訊號需求。

  • HFSS
  • RF design
  • Helical resonator
  • Directional coupler
設計範圍與技術重點

研究包含螺旋共振器與阻抗匹配元件的設計，以及用於訊號振幅監測的方向耦合器。使用 HFSS 進行射頻結構的電磁模擬。

工作重點是將元件設計、訊號傳輸與監測需求整合到實驗環境中。

03 / MACHINE LEARNING

資料分析與模型應用

帶電粒子軌跡辨識

Machine Learning for Charged-particle Tracking

探索機器學習於帶電粒子軌跡辨識的應用。從資料特徵視覺化與篩選出發，使用 KNN 與圖神經網路（GNN），進行粒子軌跡中節點及連線的分類。

  • Machine learning
  • KNN
  • Graph neural networks
  • Data visualization
資料處理與模型方法
  • 透過視覺化檢視資料特徵，並進行特徵篩選。
  • 應用 K-nearest neighbors（KNN）方法。
  • 使用圖神經網路，處理軌跡資料中的節點與連線分類問題。
